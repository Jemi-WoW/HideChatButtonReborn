**HideChatButtonReborn** is a modern, lightweight rebuild of the classic HideChatButton addon for WoW Classic and WoW Forever.

It allows you to quickly toggle your chat visibility with a minimal button, while adding quality-of-life features such as chat indicators and toast notifications, all designed to feel native to the game.

 

#### **Features**

*   Toggle chat with a simple + / − button
*   Chat activity indicators (W, G, P, R, etc.)
*   Toast notifications for incoming messages (while chat is hidden)
*   Customizable settings

#### **Design Goals**

*   Lightweight and performant
*   Clean, Blizzard-style UI
*   Customizable but simple to use
*   Faithful to the original HideChatButton, but improved for the modern version of WoW Classic

_I have plans porting this to newer versions of WoW._
